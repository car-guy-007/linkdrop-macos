Which websites work? ＋

Works now: URLs linking directly to a downloadable media file (for example, ending in .mp4, .mov, .webm, or .mp3). Safari handles saving or opening the file.

Needs a download engine: YouTube, Instagram, TikTok, Facebook and other video pages. Those websites usually do not give the browser a plain downloadable file. Use the free Mac bridge described in the setup guide to process supported video pages without paid hosting.

Not supported: DRM-protected or inaccessible material. Only save content you have permission to download.

How do I save the video? ＋

Tap Download file. Depending on the site, Safari may download the file to Downloads or play it. If it plays, use the Share menu and choose Save to Files if offered. Sites can block saving.

In Safari, downloaded files can be found in the Files app → Downloads or the download folder selected in Safari settings.
